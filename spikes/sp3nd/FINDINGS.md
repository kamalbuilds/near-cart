Claim: A `tools/list` call made without the owner's OAuth bearer token will be rejected, so 0 authenticated SP3ND tool schemas are available anonymously.
Verdict: UNTESTED for the authenticated tools; the unauthenticated negative case is CONFIRMED.
Measured: `GET https://mcp.sp3nd.shop/mcp` returned HTTP 401 with `Missing Authorization header`; an MCP `initialize` POST also returned HTTP 401. The public resource metadata reports resource `https://mcp.sp3nd.shop/mcp`, authorization server `https://happy-dragon-88.authkit.app`, and scopes `openid profile offline_access`. Commands: `curl -sS -D /tmp/cart-sp3nd-headers -o /tmp/cart-sp3nd-body https://mcp.sp3nd.shop/mcp`; `curl -sS -X POST https://mcp.sp3nd.shop/mcp ... --data '{"jsonrpc":"2.0","id":1,"method":"initialize",...}'`.
Negative case: The no-bearer initialize request was denied with HTTP 401 (`Missing Authorization header`), so it cannot be mistaken for a successful empty tool list.
Caveat: The owner's device-code OAuth session is required to call `tools/list`, record schemas, quote an item, or verify `payment_ready`. The docs say SP3ND owns the authoritative amount, memo, recipient, and total, and payment is permitted only when `payment_ready: true`; see https://www.sp3nd.shop/mcp and `/tmp/judgepull/shop/sp3nd_shop_partner-api_docs.md` (payment gate and checkout lifecycle).
